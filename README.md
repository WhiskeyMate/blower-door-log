# Blower Door Log

Offline tablet/phone web app for HERS raters: log blower door jobs, calculate house volume
(floors plus cathedral, tray and triangle ceiling shapes), and get ACH50 (CFM50 x 60 / volume).
Includes a daily report (print/PDF, CSV, copy text) and JSON backup/restore.

Open `index.html` in a browser, or host the folder (e.g. GitHub Pages) and use
"Add to Home screen" to install it. Data is stored in the browser on the device only.
